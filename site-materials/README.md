### Проверенные факты для блоков «Об аюрведе» и «О йоге»
Банк фактов с источниками — навык `yoga-ayurveda-research` (`references/proverennye-fakty.md`). Для сайта подходят:
- **107 марма-точек в Сушрута-самхите.** Аюрведа выросла из хирургии — хорошо ложится на «врач-ортопед».
- **Тёплое масло в абхьянге — часть метода.** Для страницы массажа.
- **Дина-чарья — распорядок дня.** Блок «Режим дня по аюрведе».
- **Шесть вдохов в минуту** (Bernardi, BMJ 2001). Для мантр и пранаямы, без обещаний лечения.
