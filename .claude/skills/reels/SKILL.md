# Рилсы Real Yoga

Конвейер: тема → проверенный сценарий → озвучка (или без голоса) → тайминги → конфиг → кадры → MP4 → проверка → коммит.

Движок лежит в `videos/source/`:
- `reel.html` — сцена 1080×1920: фон с плавающими пятнами и зерном, иконки с прорисовкой линией, кольца-мандала, заголовки по словам, субтитры-караоке, прогресс-бары, финальная карточка @drkalyar.retreats.
- `configs.js` — темы (`TH.dawn`, `TH.night`, `TH.ginger`, `TH.noon`) и конфиги роликов.
- `render.js` — рендер через Playwright + ffmpeg.
- `audio/` — озвучки готовых роликов.

## Жёсткие правила

1. **Каждый текст — через навык `yoga-ayurveda-research`.** Никаких «лечит», «выводит токсины», дозировок трав, диагнозов. Пометка сцены `tag`: `📜 традиция`, `~ исследования` или `✓ …` — по степени надёжности.
2. **Не генерировать лицо и голос доктора.** Закадровый голос — нейтральный диктор, о докторе в третьем лице («Доктор Кальяр советует…»). Цифровой двойник — только по его собственной записи с согласием (HeyGen и т. п.).
3. В финале стоит «Озвучка создана с помощью ИИ» — не убирать.
4. Бренд: Real Yoga, тёмно-зелёный `#1E3B32` / кремовый, шрифты Cormorant Garamond + Manrope, аккаунт **@drkalyar.retreats**.
5. После рендера — посмотреть кадры глазами (см. шаг 6). Иконки проверять на двусмысленность: однажды «ладонь» вышла похожей на неприличный жест.

## Шаги

### 1. Сценарий
25–30 сек ≈ 330–380 знаков. Короткие фразы, пауза-точка между мыслями. 3–5 сцен, у каждой: иконка, заголовок 1–3 слова (`*слово` — акцентным курсивом), либо `sub` (подзаголовок), либо `chips` (2–3 плашки). Первая фраза — крючок.

### 2. Озвучка
vidIQ: `vidiq_voiceover_generate`, голос `nPczCjzI2devNBz1zQrb` (Brian), ≈14 кредитов за ролик. Перед этим — `vidiq_balance`. Если кредитов нет, сделай ролик без голоса: не указывай `audio`, ставь `audioEnd` = длительность, субтитры по своему темпу (~14 знаков/сек). Или попроси аудио голосом доктора/Аллы и положи в `audio/`.

Скачай mp3 в `videos/source/audio/<имя>.mp3`.

### 3. Тайминги субтитров
```bash
FF=$(command -v ffmpeg || python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
$FF -hide_banner -i audio/<имя>.mp3 -af silencedetect=n=-35dB:d=0.18 -f null - 2>&1 | grep -oE "silence_(start|end): [0-9.]+"
```
Паузы = границы фраз. Сопоставь их с фразами сценария по порядку; если пауза внутри фразы — объедини куски. `caps`: `[начало, конец, 'текст', [индексы слов для подсветки]]`. Сцена (`scenes[i].t`) начинается чуть раньше первой своей фразы.

### 4. Конфиг
Добавь в `configs.js` объект по образцу `yazyk`/`son`:
```js
novoe:{audio:'audio/novoe.mp3',audioEnd:27.5,theme:TH.night,kicker:'Аюрведа · вечер',
  scenes:[{t:0,icon:'moon',head:'Вечерний *ритуал',sub:'…',tag:'📜 традиция'}, …],
  caps:[[0,2.2,'Фраза.',[1]], …]},
```
Иконки (`ICONS` в `reel.html`): scroll, scraper, sunrise, eye, moon, foot, oil, phone, stars, ginger, flame, heart, bookmark, sunarc (солнце идёт по дуге), zenith, plate, clock, week. Новую иконку — добавить в `ICONS` как SVG-пути в viewBox 400 (контур, без заливки).

### 5. Рендер
```bash
cd videos/source
pip install -q imageio-ffmpeg   # если нет ffmpeg
NODE_PATH=$(npm root -g) OUT_DIR=<scratchpad> node render.js novoe still 1,8,15,29   # пробные кадры
NODE_PATH=$(npm root -g) OUT_DIR=<scratchpad> node render.js novoe video             # ~1–2 мин
```
Несколько роликов можно рендерить параллельно (`&` + `wait`).

### 6. Проверка
Склей пробные кадры (`ffmpeg … hstack`) и посмотри через Read: читаемость, переносы заголовков (одно слово на строке — перефразируй), наложения плашек на субтитры, смысл иконок. Проверь `ffmpeg -i out.mp4`: 1080×1920, есть аудио.

### 7. Отдача
Скопируй в `videos/reel-<N>-<тема>.mp4` (<30 МБ — иначе не уйдёт файлом), закоммить вместе с изменениями `configs.js`/`audio/`, запушь, отправь через SendUserFile. Напомни про ручное указание «создано с ИИ» в Instagram при публикации.
