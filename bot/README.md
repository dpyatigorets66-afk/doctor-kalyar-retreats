# Telegram-бот Real Yoga — этап A: основа и защита

Этот этап — фундамент для рассылок (C), касаний клиентской базы (D) и ответов в группах (E).
Сам бот уже работает: принимает подписчиков, отвечает, пересылает вопросы админам,
даёт админ-панель с кнопкой «⛔ Стоп всё» и присылает ежедневную сводку.

## Запуск

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
. .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # заполнить BOT_TOKEN и ADMIN_IDS
python -m bot
```

- `BOT_TOKEN` — токен от @BotFather.
- `ADMIN_IDS` — числовые id админов через запятую (свой id подскажет @userinfobot).
  Админ должен один раз нажать /start у бота, иначе Telegram не даст боту ему написать.

База — SQLite-файл `data/bot.sqlite3`, создаётся сам.

## Что умеет бот

**Подписчики**
- `/start` — подписка на анонсы (только так человек попадает в список рассылки).
- `/stop` или кнопка «Не присылать анонсы» — отписка.
- Стоп-слова («стоп», «не пишите», «спам», «stop», «unsubscribe», «кто вы», «откуда номер») —
  человек навсегда попадает в стоп-лист, отписывается от анонсов, бот один раз извиняется.
  «Массаж стоп» и «крем для стоп» стоп-словом не считаются.
- Любое другое сообщение пересылается админам, человеку приходит короткое «передано команде».

**Админ** (`/admin`)
- «⛔ Стоп всё» — мгновенно останавливает рассылки, касания, ответы в группах и вступления
  в группы до нажатия «▶️ Включить всё». Переживает перезапуск бота.
- Статус защиты: паузы, прогрев аккаунта, лимиты на сегодня; кнопки снятия пауз,
  которые требуют ручного включения.
- `/summary` или кнопка «📊 Сводка» — сводка за сегодня. Автоматически приходит в `SUMMARY_HOUR`
  (по умолчанию 21:00 по Бангкоку): сколько отправлено, сколько ответили, сколько написали «стоп»,
  сколько отписались и заблокировали бота, сколько отправок отклонила защита.
- `/warmup_start 2026-10-14` — дата, когда Telethon-аккаунт начал работу. Без неё касания запрещены.

## Модуль защиты `bot/safety.py`

Всё исходящее проходит через `Safety.check()`: бот отправляет только через `bot/sender.py`,
а этапы C–E должны отправлять только через `Safety.send_guarded()`. Каждое решение
(разрешено или нет и почему) пишется в таблицу `safety_log` и в лог.

| Канал | Что проверяется |
|---|---|
| `BROADCAST` (C) | «Стоп всё»; блок рассылок; человек сам нажал /start, не отписался и не заблокировал бота; не чаще раза в `BROADCAST_MIN_DAYS`; есть кнопка «Не присылать анонсы»; указан `campaign` |
| `OUTREACH` (D) | «Стоп всё»; флуд-пауза 48 ч; ограничение от @SpamBot; пауза после «стоп»; стоп-лист; только одно касание; прогрев 7 дней; лимит 5 → 10 → `OUTREACH_DAILY_LIMIT`; 10:00–19:00 по Бангкоку, не в воскресенье; случайная пауза 4–12 минут; текст до 300 символов, без ссылок и @упоминаний, без капса, не больше 2 эмодзи, «ассистент Real Yoga», без «я доктор» и «меня зовут», в конце фраза про «стоп»; не похож больше чем на 70% на последние 50 отправленных |
| `GROUP` (E) | «Стоп всё»; паузы аккаунта; чёрный список групп; в группах «без рекламы» не отвечаем; оценка модели не ниже 8; кнопка админа (автопилот выключен); 1 ответ на группу в день и не больше `SCOUT_DAILY_LIMIT` за день; без ссылок; последняя строка «Подробнее — в личку» |
| `GROUP_DM` (E) | личка автору вопроса: всегда только после кнопки админа, стоп-лист, одно касание, без ссылок, общий лимит с `GROUP` |
| `JOIN` (E) | не больше 2 новых групп в день, не в группы из чёрного списка |
| `ADD_MEMBER` | запрещено всегда |
| `REPLY` | ответ только тому, кто сам писал за последние 24 часа; «Стоп всё» не мешает отвечать |
| `ADMIN` | только на id из `ADMIN_IDS` |

Сигналы, которые этапы C–E передают в safety:
- `record_blocked(user_id)` — бота заблокировали. Если после рассылки заблокировали больше 3%
  получателей, следующие рассылки блокируются, админу уходит уведомление.
- `register_stop(recipient, source="account")` — стоп-слово аккаунту. Больше 2 за день — касания на паузу.
- `on_flood("PeerFloodError")` / `on_flood("FloodWaitError", seconds)` — пауза аккаунта на 48 часов.
- `on_spambot_reply(text)` — ежедневная самопроверка через @SpamBot. Ограничение (или непонятный
  ответ) останавливает все действия аккаунта до ручного включения.
- `on_group_penalty(group_id, reason)` — сообщение удалил админ или аккаунт исключили: группа в чёрный список.
- `outreach_text_issues(text)` — проверить текст до отправки и, если надо, попросить Claude переписать.

Уведомления админу копятся в таблице `admin_alerts`, бот рассылает их каждые 5 секунд.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Покрыты лимиты, прогрев, рабочие часы, похожесть текстов, стоп-слова, «Стоп всё»,
флуд и @SpamBot, блокировки после рассылки, сводка и обработчики бота.
